# The tells: what makes a site look generated

A reference catalog of the patterns that mark a page as machine-made, and what
to reach for instead. Treat the checklist at the bottom as a gate before
shipping.

## Color

| Tell | Reach for instead |
| --- | --- |
| Indigo → purple → pink hero gradient | One sourced accent color over a calm, slightly-off-neutral background (warm grey, bone, ink, near-black) |
| Three gradients on one page | At most one gradient, and only if it has a reason to exist |
| Pure `#ffffff` / `#000000` everywhere | Tinted neutrals — a white that leans warm, a black that's really #14110F |
| Random "vibrant" accent with no logic | A palette pulled from the subject (product, photo, brand) |

## Typography

| Tell | Reach for instead |
| --- | --- |
| Inter / Roboto / Open Sans for the entire page | A characterful display face paired with a clean text face |
| One weight, one size, no real hierarchy | A deliberate type scale; contrast in weight and size that guides the eye |
| Everything center-aligned | Left-aligned text with intentional ragged edges; center sparingly |
| Default line-height and measure | Tuned leading and a comfortable measure (~60–75 chars) |

## Layout

| Tell | Reach for instead |
| --- | --- |
| Centered hero + two pill buttons + tagline | A layout shaped by the actual content and the one action that matters |
| Three- or four-card feature grid, equal sizes | Varied module sizes; asymmetry; a real editorial rhythm |
| Emoji as section icons (🚀 ✨ ⚡ 🎯) | A consistent, chosen icon set — or no icons, just type |
| Endless evenly-spaced vertical sections | Varied density; sections that breathe differently on purpose |
| Everything in a 1200px centered container | Full-bleed moments, offset columns, content that uses the edges |

## Copy

| Tell | Reach for instead |
| --- | --- |
| "Empower / Unlock / Supercharge your workflow" | Plain language that says what the thing actually does |
| "Welcome to our platform" | A real opening line a knowledgeable person would write |
| Lorem ipsum left in | Real or realistic content, even if you have to draft it |
| Three benefits that could describe any product | Specifics — numbers, names, concrete claims |

## Effects

| Tell | Reach for instead |
| --- | --- |
| Glassmorphism on every card | Intentional, sparing use — or solid, well-bordered surfaces |
| Blurred gradient "blobs" in the background | Texture with a purpose: grain, a real image, a subtle pattern |
| Heavy drop shadows on everything | Flat or finely-tuned elevation; hairline borders do a lot of work |
| Float-in-on-scroll on every element | Motion only where it adds meaning, tuned to feel deliberate |

## The checklist

Run this before declaring a page done. Any "yes" needs a deliberate reason or a
change.

- [ ] Is the hero a centered headline + subhead + two pill buttons?
- [ ] Is there a purple/indigo gradient doing the heavy lifting?
- [ ] Are section headers decorated with emoji?
- [ ] Is the whole page set in Inter/Roboto with no display face?
- [ ] Is it a stack of equal, evenly-spaced, centered sections?
- [ ] Is there a three-card feature grid with icon + title + one sentence?
- [ ] Does the copy use "empower / unlock / supercharge / seamless / elevate"?
- [ ] Could this exact layout belong to any company in any industry?

If you can't answer "no" to all of them with a clear conscience, it still looks
generated.
